## 🚀 Primary Project: VoltCast V4
**Advanced Regional Electricity Load Forecasting**

[**View Project Folder →**](./Voltcast_v4)

**VoltCast V4** is a state-of-the-art forecasting system designed to predict regional electricity demand (ISO-NE) with high precision. It addresses the critical challenge of grid stability and energy market efficiency.

### 🌟 Key Technologies
- **AI/ML:** PyTorch (Deep Learning), XGBoost (Ensemble), Scikit-Learn.
- **Backend:** Flask, Python, SQLite.
- **Frontend:** Vue 3, Vite, Chart.js.
- **Architecture:** Hybrid Residual Blending Strategy.

### 📈 What's Inside?
- **Hybrid AI Engine:** A sophisticated ensemble that blends neural networks with gradient-boosted trees.
- **Live Dashboard:** An interactive visualization tool for real-time forecast monitoring.
- **Comprehensive Pipelines:** Full Jupyter notebooks tracing data extraction, processing, and model evaluation.
